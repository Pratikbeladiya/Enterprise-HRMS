Project: HRMSfrontend
Location: HRMSfrontend/ (workspace subfolder)

Purpose:
- Frontend for HRMS (React + Vite + Tailwind).
- Lightweight single-page app using React 19 and Vite.

Repository structure (top-level of the frontend folder):
- package.json: scripts and dependencies
- vite.config.js: Vite configuration
- tailwind.config.js: Tailwind setup
- public/: static assets
- src/: React source files (App.jsx, Login.jsx, main.jsx, index.css)
- eslint.config.js: ESLint configuration

How this note set is organized:
- FILES_LIST.txt — inventory and short descriptions of key files
- SETUP_AND_RUN.txt — commands to install and run locally
- DEPENDENCIES.txt — extracted dependency lists and versions
- DEV_NOTES.txt — runtime notes and issues encountered while running the dev server
- TODOS.txt — suggested next steps and actionable items
